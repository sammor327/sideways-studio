# Sideways Studio

Broadcast graphics for Riftbound streams: one portable Windows app that
serves every graphic to OBS or vMix as a 1920x1080 browser source. Built by
Sam Morris / Turn'em Sideways.

**Download the latest build under [Releases](https://github.com/sammor327/sideways-studio/releases/latest).**
Run `SidewaysStudio.exe`; it opens the control panel in your browser and
checks this page for updates on every launch.

This repository carries the releases only. The source code is not
published; each release here is pinned to this branch, so the "source code"
archive GitHub attaches to a release holds this page and nothing else.
